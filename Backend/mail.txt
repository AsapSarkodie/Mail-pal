//TIPS from this Project
Controller: handles the HTTP side. It reads the request (req.body, req.params), 
calls a service, and sends the response (res.json, status codes).

Service: handles the business logic and database work. 
It knows nothing about req or res. It just takes plain data, does the work, and returns a result.
